# Domain Docs

## Exploration

Read [GLOSSARY.md](../../GLOSSARY.md) for domain vocabulary and the relevant decisions in
[docs/adr/](../adr/) before exploring the code.

Use the glossary's terms in issue titles, proposals, hypotheses and tests. If a concept is
missing, check whether an existing term covers it; record a genuine gap for `/domain-modeling`.

## Decisions

When a proposal conflicts with an ADR, name the decision and explain why it should be reopened.
Use `/domain-modeling` when changing vocabulary or recording a decision; reading the existing
references does not require invoking it.
